# Last Card

A real-time multiplayer card game for 2 to 8 players. Match the top card by color, number or symbol, use action cards to skip, reverse and make others draw, and be the first to empty your hand.

Open a table, share the four-letter code or invite link with friends, and play together in the browser. Bots can fill empty seats, and there's a solo practice mode.

- **Classic:** match by color, number or symbol, with challengeable Wild Draw Fours.
- **Wild Rush:** every card is a wild, including Wild Swap, which trades hands with a player you choose.
- **Stacking:** an optional house rule that lets you pass a Draw Two or Wild Draw Four penalty along, so it keeps growing.
- **Reactions and sound:** send emoji reactions to the table, with sound effects for every play.
